# 20 年维护路线

## 现实边界

Apple 不会给一台 2020 款 M1 提供 20 年官方支持。这个计划的目标是：

- 2026–2030：作为可靠主力/副机；
- 2031–2035：冻结系统，继续办公和离线任务；
- 2036 以后：Linux、离线系统、媒体/归档用途；
- 持续可修、数据可迁移、硬件可更换。

## 阶段计划

| 阶段 | 系统 | 用途 | 行动 |
|---|---|---|---|
| 2026–2028 | macOS 13/14/15 | 主力 | 裁剪、低内存软件、电池维护 |
| 2029–2031 | 最后一个安全版本 | 主力/副机 | 冻结升级，年度清理 |
| 2032–2035 | 冻结 macOS | 办公/媒体/远程 | 换电池，备份，减少联网 |
| 2036–2040 | Asahi Linux / 离线 macOS | 文档/终端/媒体 | 替换零件，离线数据 |
| 2041–2046 | 离线系统镜像 | 归档/复古 | 数据迁移，硬件修复 |

## 硬件维护

### 电池

- 3–5 年或健康度低于 80% 时考虑更换。
- 长期插电时可用 AlDente 限制到 70–80%。
- 避免长期高温 + 满电。

### SSD

- 保持 10–20% 空闲空间。
- 减少 swap：少开浏览器标签、少跑虚拟机、不要禁用内存压缩。
- 每年检查磁盘写入量和健康状态。

### 散热

- MacBook Air M1 无风扇，长时间满载会降频。
- 避免床上、沙发等堵住底部的环境。
- 不要把长期编译/转码/本地大模型当日常任务。

### 其他零件

- 屏幕、键盘、触控板、电池、接口板都可能需要维修。
- 保留一套原装充电器和线材。

## 软件生命周期

### 2026–2030

- 选 macOS 13/15。
- 执行本仓库裁剪。
- 软件只保留必要常驻。
- 每年一次完整备份。

### 2031–2035

- 冻结在最后一个能收到安全更新的版本。
- 浏览器保持更新；停止使用的软件卸载。
- 关闭不需要的云同步。

### 2036 以后

- 考虑 Asahi Linux。
- 保留一个离线 macOS 分区作为兼容层。
- 数据以开放格式保存：Markdown、PDF、PNG、FLAC、MP4。

## 数据计划

- 3-2-1：3 份数据、2 种介质、1 份异地。
- 每年做一次离线归档。
- 不要只依赖 iCloud。
- 保留系统安装器和恢复镜像。

## 年度检查清单

- [ ] 电池健康 / 循环次数
- [ ] 磁盘空闲 / SSD 健康
- [ ] 内存压力 / swap
- [ ] LaunchAgents / 登录项
- [ ] 浏览器扩展
- [ ] 软件更新
- [ ] 完整备份
- [ ] 清理不需要的常驻
