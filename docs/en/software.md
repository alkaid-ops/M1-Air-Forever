# Software Recommendations

Goal: fewer background processes, fewer Electron apps, and only the tools that actually help.

## Keepers

| Tool | Purpose | Link |
|---|---|---|
| Rectangle | Window management | <https://rectangleapp.com/> |
| Shottr | Screenshots and annotation | <https://shottr.cc/> |
| Flameshot legacy builds | macOS 11+ screenshots | <https://github.com/alkaid-ops/flameshot-legacy-builds> |
| LocalSend | Local file transfer | <https://localsend.org/> |
| KeepingYouAwake | Prevent sleep | <https://keepingyouawake.app/> |
| Clash Verge | Network proxy | <https://github.com/clash-verge-rev/clash-verge-rev> |
| Sogou Input | Chinese input | Official download |

## Browsers

| Choice | Notes |
|---|---|
| Safari | Lightest, best power efficiency |
| Orion | WebKit with Chrome extension support |
| Chrome | Best compatibility, highest RAM |
| Firefox | Balanced, still memory-hungry |

Keep one browser resident most of the time.

## System utilities

- Stats
- Ice / Hidden Bar
- AppCleaner
- MonitorControl
- AlDente
- Itsycal

## Media

- IINA
- VLC
- mpv
- HandBrake (on demand)

## Development

- VS Code (limit extensions)
- Zed / Sublime Text / Neovim
- Xcode only when needed
- Docker only on demand

## Office and notes

- Apple Notes
- Obsidian (one vault)
- Typora
- LibreOffice / Microsoft Office

## Security

- LuLu
- KnockKnock
- Malwarebytes (on demand)

Do not run multiple antivirus/firewall agents.

## Avoid resident bloat

- Multiple cloud sync clients
- Adobe Creative Cloud background
- Multiple browsers at once
- Game launchers
- Auto-updaters
- Desktop widget suites
